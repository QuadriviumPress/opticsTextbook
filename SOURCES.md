## Embedded simulations

Interactive figures embed simulations hosted by their authors, in an iframe,
with a caption link back to the running simulation; no simulation code is
copied into this repository. Directives come from
[`plugins/simulation.mjs`](plugins/simulation.mjs) (the same plugin pattern as
`modernPhysics`): `{phet}`, `{phet-legacy}`, `{openlyceum}`, and `{simulation}`.
